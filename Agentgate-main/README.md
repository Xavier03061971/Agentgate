# AgentGate

AgentGate is an AI Agent Governance Layer designed to inspect agent actions before execution.

## Features

- Hybrid risk engine
- Semantic analysis
- Explainable decisions
- Governance workflow
- Allow / Review / Block decisions
- Audit logging
- Streamlit dashboard

## Stack

- Python
- Streamlit
- FastAPI

## Demo Decisions

- Send email → REVIEW
- Delete customer data → BLOCK
- Read internal data → ALLOW
- Permission changes → BLOCK

## Vision

AgentGate provides governance and oversight for autonomous AI agents.
